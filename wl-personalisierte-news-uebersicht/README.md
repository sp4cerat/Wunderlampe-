# wl-personalisierte-news-uebersicht

Eine Webseite, die dem User täglich die wichtigsten Nachrichten zusammenfasst und nach persönlicher Relevanz sortiert anzeigt.  Quellen: selbst eingegebene RSS-Feeds + Websuche (DuckDuckGo, ggf. Google/Bing) für Events und Aktien-News.

Mit [Wunderlampe](https://test.svenforstmann.com/wunderlampe/) gebaut.
