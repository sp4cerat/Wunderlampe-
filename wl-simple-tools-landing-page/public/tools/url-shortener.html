URL-Shortener

Privater, temporärer Kurzlink-Dienst mit TTL.

Nicht verfügbar

Dieser Dienst braucht einen laufenden Backend-Server, um Kurzlinks zu speichern und unter /s/<id> aufzulösen. In der statisch ausgelieferten Version des Toolkits gibt es keinen Server — der Shortener kann hier nicht arbeiten.

Alternativen, die ohne Server auskommen:

  • QR-Code aus der langen URL erzeugen (rein clientseitig möglich).
  • Externe Anbieter wie is.gd oder tinyurl.com.
  • Lokal das mitgelieferte node server.js starten — dann steht dieser Endpoint wieder zur Verfügung.
