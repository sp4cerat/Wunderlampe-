Hintergrund transparent machen

Pixel (0,0) wird als Schlüsselfarbe genommen. Pixel innerhalb des Threshold (RGB-Distanz) werden voll transparent.

Tipp: Threshold 0 ersetzt nur exakt diese Farbe. Höhere Werte erfassen ähnliche Pixel — gut bei JPEG-Artefakten.
