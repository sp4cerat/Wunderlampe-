Wo läuft das?

Alle Tools rechnen direkt in deinem Browser — Bild-Operationen via Canvas, PDFs via pdf-lib. Kein Backend nötig. Der URL-Shortener braucht einen Server und ist hier offline.

Privatsphäre

Keine Telemetrie, keine Cookies, keine Uploads. Dateien werden ausschließlich lokal in deinem Browser verarbeitet.

Tech-Stack

Statisches HTML/JS · Tailwind · Canvas · pdf-lib · marked + DOMPurify. Keine SPA, keine Bundles.
